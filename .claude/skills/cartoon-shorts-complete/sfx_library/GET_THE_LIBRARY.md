# Sound library: separate download

The sound files are in a second zip, `Bookshelf_Sound_Library_v1.1.zip`, from the same place as this pack (it's
split off to stay under upload size limits). Unzip it into `skills/cartoon-shorts-complete/` (or into
`~/.claude/skills/cartoon-shorts-complete/` after installing): it adds this `sfx_library/` folder with `kenney/`,
`bigsoundbank/` and `music/`. `CATALOG.md` lists every file.

Without it the pack still works: Claude downloads the sounds it needs online (rules/sound.md, "Getting the sounds").
