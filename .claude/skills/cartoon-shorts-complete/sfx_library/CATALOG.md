# Sound library (all CC0: free to use, no credit required, can be redistributed)

Ready-made real recordings, so a short has sound even before anything is downloaded. Paths are relative to this
folder (`sfx_library/` inside the cartoon-shorts-complete skill). Copy what a short uses into the project's `sfx/`
folder and add a line per file to `sfx/CREDITS.txt`. When a sound you need is not here, download more with the steps
in `rules/sound.md` ("Getting the sounds").
