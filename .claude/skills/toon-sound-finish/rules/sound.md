# Sound, music, subtitles and finishing: the rules

## Where sounds come from
- Never AI-generated sound effects, and never sounds generated by code. They sound fake next to real pictures.
  Use recordings and sounds made by human sound designers (Kenney's interface and sci-fi packs count; they are
  fine for clicks, pops and stylised moments):
  - your own recordings or packs you own;
  - Kenney audio packs (CC0): impacts, interface, RPG, sci-fi, footsteps, doors, cloth, glass;
  - BigSoundBank (CC0): real cars passing, engines, cabin hum, saws, splashes, machines;
  - OpenGameArt filtered to CC0.
- Keep a `CREDITS.txt` with each file, its source and its licence.
- No birds, no stock "nature ambience" packs. Wind beds outdoors, cabin hum inside cars, room tone indoors.
- Keep every download in its own folder (`sfx/kenney`, `sfx/bigsoundbank`, `sfx/mine`).

## Getting the sounds (Claude does this; don't leave it to the user)
The pack ships a CC0 starter library (`sfx_library/` in the cartoon-shorts-complete skill: Kenney packs, 28 real
BigSoundBank recordings, music). Anything the library doesn't have, Claude finds and downloads itself. A short with
no sound effects is not finished, and "the user didn't provide sounds" is not a reason to skip them.
1. **List** every sound the short needs, from the animation's events: doors, steps, engines, impacts, cloth, wind,
   whooshes. Check the pack's own library first: `sfx_library/` inside the cartoon-shorts-complete skill
   (normally `~/.claude/skills/cartoon-shorts-complete/sfx_library/`; `CATALOG.md` there lists every file). Then the
   project's `sfx/` and any sound folders the user has. Only download what is still missing.
2. **Ask once.** Claude Code treats downloading files as an action that needs the user's OK. Ask in ONE message,
   listing each file (name, site, size), e.g. "OK to download 3 CC0 sounds from bigsoundbank.com: car door (0.6 MB),
   ...?". On a yes, download them all; don't ask again for each file. If the user says no, use only what is on disk
   and say which sounds are missing.
3. **BigSoundBank** (CC0, best for real cars, engines, doors, machines, rain, splashes):
   - Search: web search `site:bigsoundbank.com car door slam` (or restrict the search to the domain bigsoundbank.com).
   - Each sound page ends in its number, e.g. `https://bigsoundbank.com/car-door-1-s0971.html` is number `0971`.
   - The mp3 is `https://bigsoundbank.com/UPLOAD/mp3/<number>.mp3`. Download it with
     `curl -sL -A "Mozilla/5.0" -o sfx/bigsoundbank/car_door_s0971.mp3 https://bigsoundbank.com/UPLOAD/mp3/0971.mp3`
   - Check every file before using it: `ffprobe` it (it must be audio, with a sensible duration) and check its
     loudness with ffmpeg `ebur128` or `astats` (Claude can measure sound but can't hear it).
4. **Kenney** (CC0, best for footsteps, impacts, cloth, UI clicks, whooshes). The download button runs a script, so
   a plain request gets "forbidden". This works (tested 2026-11-26): open the pack page with a cookie jar first, then ask
   for the download link with the same cookies and the page as Referer, then download the zip it returns:
   ```
   p=impact-sounds; id=$(python -I -c "print('assets/$p'.encode().hex())")
   curl -sL -A "Mozilla/5.0" -c k.txt -b k.txt "https://kenney.nl/assets/$p" -o /dev/null
   url=$(curl -sL -A "Mozilla/5.0" -c k.txt -b k.txt -H "Referer: https://kenney.nl/assets/$p"          "https://kenney.nl/download-link/$id" | python -I -c "import json,sys;print(json.load(sys.stdin).get('url',''))")
   curl -sL -A "Mozilla/5.0" -o sfx/kenney/$p.zip "$url"
   ```
   Useful packs: `impact-sounds`, `interface-sounds`, `rpg-audio`, `sci-fi-sounds`. Unzip each into
   `sfx/kenney/<pack>/`. If this fails (the site may change), use a browser tool if Claude has one, or ask the user
   to download the packs from kenney.nl. Include these packs in the single permission message of step 2.
5. **OpenGameArt** (filter the licence to CC0): music and some effects. The file link on the page
   (`https://opengameart.org/sites/default/files/...`) downloads with curl. If the site blocks the request, ask the
   user to download it.
6. **Credits:** add one line per file to `sfx/CREDITS.txt`: file, title, page URL, licence.
7. **Safety:** keep downloads in their own folder, never run or open downloaded files as code, and only take audio
   files (mp3, ogg, wav) from these sites.

**If downloads keep getting blocked:** the person's Claude Code permission settings may refuse web downloads
without asking. Tell the user plainly, and ask them to approve the download when the prompt appears. If no prompt
appears, they can add an allow rule in Claude Code's settings (`.claude/settings.json`, under `permissions.allow`),
for example `"WebFetch(domain:bigsoundbank.com)"` and `"Bash(curl:*)"`, or download the files themselves into `sfx/`.

## Where sounds go
- A sound lands on the exact frame of the visible action: the crunch on the frame of the crash, the door on the
  frame it unlatches, every footstep on its foot plant. Work from the animation's own times (shot start + event time).
- Layer the big moments: a crash is a crunch + heavy metal + a little glass, each a few hundredths of a second apart.
- Big camera swings get a soft woosh whose peak (not its start) lands on the fastest part of the move.
  Use `"peak"` in the cue sheet.
- Engines and machines follow what is on screen: they fade when the camera climbs away, they speed up in a timelapse
  (`atempo`), and they stop when the shot changes place.
- Continuous beds (wind, hum) are laid with a fixed-count loop with fades. Never use a while loop: one that never
  advanced once filled the RAM and crashed the computer.
- Rhythmic effects (rumble strips) can be made from a real recording processed with ffmpeg
  (`tremolo`, `lowpass`), never from a synthesiser.
- Less is more: one clear sound per action beats five stacked ones. Nothing should cover the voice.

## Levels
- Voice: loudness-normalised to -14 LUFS (`loudnorm=I=-14:TP=-1.5`).
- Sound effects: the master gain is about 0.7, and each cue is set by hand (0.1 to 1.0).
- Music: about -21 LUFS for the stem, under the voice. Adjust it in the music picker by watching, not by numbers.
- Final: about -14 LUFS integrated, true peak under -1 dB, with a limiter at 0.89.
- Measure each stem and the final with `ebur128` and say the numbers. Audio can be measured but not heard by Claude:
  say so.

## Music
- The style must fit the story (western for a country road, light and playful for comedy). Never sad and never
  recognisable. Free or licensed tracks only, credited.
- Choose it with the picker: every track plays over the rendered video with the voice and sound effects, with a live
  volume slider. Then press Save as final, and the mix reads `music_choice.json`.
- Fade in 0.25 s and out over the last 1.2 s. Loop a short track instead of stopping it.

## Subtitles
- Word timings from the voice with Whisper (`tools/transcribe.py`). Compare every word with the script and fix
  mishearings (numbers, names, "guard rails"), so the subtitles match the script exactly.
- One word at a time, big white heavy font with a black outline and soft shadow, at about 70% of the height, with a
  small pop on each word (`tools/subs_overlay.js`).
- Make subtitles a separate transparent overlay and lay it on the clean picture with ffmpeg. Never bake them into the
  render: fixing a word must not need a re-render.

## Finishing checklist
1. The clean render's frame count equals the voice length × fps.
2. Overlay the subtitles, then the mix (`tools/mix_cues.py`), checking the duration.
3. Loudness numbers for voice, sound effects, music and final.
4. A contact sheet of the final (one frame a second) and close-ups of the key moments.
5. Spot-check sync: take a still at each big sound's time and see the action in it.
6. Say what was not checked.
